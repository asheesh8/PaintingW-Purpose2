# Painting With Purpose: website demo 2

A cinematic, scroll-driven site for [paintingwithpurpose.com](https://paintingwithpurpose.com), modeled on a "$10k build" feel: pinned scroll scenes, an arched window that opens onto the hero photo, a drawing that gets painted as you scroll, a sideways project reel and drifting review columns. Every image is one of Gabe's real photos. Demo 1 is the quiet minimalist sibling.

There's no build step to deploy. Every page is plain HTML, CSS and JS.

## Run it locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Logo

`assets/logo.png` is the current PWP logo and is used in the header and footer. Swap the file to update it everywhere.

| File | What's on it |

## Editing

Pages are generated by `tools/build.py`, which holds the copy and project list. The before/after pairs live in `assets/js/projects.js`. Edit either one, then run `python3 tools/build.py` from the repo root.

```
assets/
  css/site.css        base styles
  css/cine.css        cinematic layer: fonts, dark sections, scroll scenes
  js/cine.js          scroll scenes (each .scene gets --p from 0 to 1)
  js/site.js          header, menu, sliders, reveals, demo forms (no libraries)
  js/projects.js      before/after data
  photos/             client photos (-sm 900px, -lg 2000px)
  before-after/       21 before/after pairs from the current site
  logo.png            logo slot
tools/build.py        page generator
```
