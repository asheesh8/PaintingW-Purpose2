# Demo 2: ChatGPT image prompts (watercolor set, full resolution)

The watercolor set you sent came through at about 300px per piece, so demo 2 shows those pieces small, as spot illustrations and postcards. Generate each one below **on its own** and save it with the exact filename shown into `assets/art/` (replacing the file that's there). Keep the `.jpg` name; if ChatGPT gives you a PNG, convert it to JPG first (Preview → Export works). The site picks it up automatically, with no code changes.

**Tip:** generate one, then reply "Same style, next one:" plus the next prompt, so the whole set stays consistent. If any text or letters show up, reply "Same image, remove all text and lettering."
